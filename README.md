# 🛒 Online Shopping SQL Analysis

## 📌 Project Overview

This project focuses on analyzing an Online Shopping database using SQL.

The database contains information about customers, products, orders, payments, inventory, reviews, shipping, wishlist, and suppliers.

The main goal is to understand customer behavior, sales performance, product performance, orders, payments, and other business insights using SQL.

---

## 🎯 Objectives

- Analyze customer purchasing behavior
- Analyze product and category performance
- Analyze orders and order items
- Analyze payment methods
- Analyze inventory and suppliers
- Analyze customer reviews and ratings
- Identify useful business insights using SQL
- Practice SQL queries for Data Analyst interviews

## 💡 Key Analysis Questions

1. How many customers are registered?
2. How many products are available?
3. What are the top-selling products?
4. Which categories generate the highest sales?
5. Which customers place the most orders?
6. What payment methods are most commonly used?
7. Which products have the highest ratings?
8. What is the total sales revenue?
9. Which products have low inventory?
